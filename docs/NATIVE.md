# Provider native

| Baseline | Jalur baca-saja | Batas data |
| --- | --- | --- |
| macOS 14+, arm64 dan amd64 | Interval CPU dengan `top`, halaman RAM dengan `vm_stat`, boot dan RAM total dengan sysctl, volume startup dengan `statfs`, proses dengan `ps`, serta daya dan status baterai dengan `pmset -g batt`. | RAM bebas adalah batas bawah. Persentase proses `ps` adalah rata-rata yang meluruh. Volume APFS berbagi ruang dalam container sehingga kapasitas tidak dijumlah. Sensor suhu CPU dan perubahan profil belum tersedia melalui provider ini. |
| Windows 11 atau Windows Server 2025, amd64 dan arm64 | Win32 untuk CPU, RAM, drive tetap dengan huruf, daftar proses, waktu aktif, serta baterai, AC, dan flag pengisian. | CPU sistem pada host dengan lebih dari 64 CPU logis ditandai parsial karena kelompok prosesor. Proses terlindung dapat dilewati. RAM berasal dari tersedia fisik, dan swap Windows tidak disimpulkan dari batas commit. |
| macOS, drive fisik yang terlihat dari Disk Utility | `diskutil list -plist physical` lalu `diskutil info -plist` untuk SMART yang dilaporkan perangkat. System Information untuk dukungan TRIM NVMe/SATA yang terlihat. | Disk image dan volume logis bukan disk fisik. Alat sistem atau bridge USB dapat menyembunyikan SMART. Dukungan TRIM yang terlihat tidak memverifikasi eksekusi discard per volume. |
| Windows, disk yang terlihat dari Storage Provider | Windows PowerShell Storage menghimpun kesehatan drive dan counter reliabilitas. `fsutil behavior query DisableDeleteNotify` membaca kebijakan notifikasi NTFS/ReFS. | Kesehatan provider bukan atribut SMART mentah. Izin dapat berbeda antara health dan counters. Kebijakan notifikasi bukan bukti discard per volume. |
| macOS APFS dan Windows NTFS lokal | Inventaris volume dan pemeriksaan eksplisit dengan `fsck_apfs -n` atau CHKDSK baca-saja. | Perlu izin root atau Administrator. Pemeriksaan volume aktif menghasilkan bukti parsial. Perbaikan native Linux ext dijelaskan bersama [cara memeriksa APFS dan NTFS](FILESYSTEM.md). |

Metrik lokal tidak mengirim data melalui jaringan. Status alat hilang, izin, data tidak tersedia, dan galat dipertahankan. Laporan menyimpan keluarga sumber dan metrik yang diizinkan, dengan nama proses, label volume, serial, dan model drive disaring.

Windows menghitung seluruh prosesor logis aktif dengan `GetActiveProcessorCount`. Pada mesin dengan lebih dari 64 prosesor logis, sampel `GetSystemTimes` diambil dari satu thread OS dan diberi label grup prosesor primer di TUI, JSON, dan Markdown. Diagnosis beban seluruh host melewati sampel satu grup tersebut. Persentase proses memakai kapasitas seluruh prosesor logis aktif. Perilaku 128 CPU diperiksa dengan fixture. [GetSystemTimes](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-getsystemtimes) · [GetActiveProcessorCount](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getactiveprocessorcount) · [GetProcessTimes](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-getprocesstimes)

`whwmpc power` menampilkan status daya dan bacaan baterai yang tersedia. Persentase atau status baterai tanpa sumber daya yang diketahui menghasilkan cakupan parsial. `whwmpc trim` menampilkan cakupan dukungan macOS atau kebijakan notifikasi penghapusan Windows. Laporan Markdown mencantumkan status drive dan counter yang dilaporkan Windows Storage. [Flag daya Win32](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-system_power_status) · [Kebijakan notifikasi Windows](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/fsutil-behavior).

Workflow native menjalankan `power`, `trim`, dan `check --json` melalui executable yang baru dibangun. Semua target macOS dan Windows amd64/arm64 lulus di `c79c5c9`. Runner Windows membaca status kesehatan dua disk virtual dan dua kebijakan notifikasi. Disk virtual macOS melaporkan SMART unsupported dan dukungan TRIM unknown. Seluruh runner melaporkan daya tersedia tanpa bacaan baterai. [Hasil CLI native](https://github.com/christiandoxa/whwmpc/actions/runs/45011977359)

CI lulus pada macOS 15 amd64/arm64, Windows Server 2025 amd64, dan Windows 11 arm64. Inventaris native dan pemeriksaan image APFS/NTFS berjalan dengan checksum image yang tetap sama. Runner macOS Intel dan Windows ARM melaporkan daya tetapi tidak mendeteksi baterai. Validasi pengisian fisik, SMART penuh, dan volume fisik memerlukan perangkat terpisah. Runner macOS 14 telah dipensiunkan GitHub.
