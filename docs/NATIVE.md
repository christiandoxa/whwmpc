# Provider native

| Baseline | Jalur baca-saja | Batas data |
| --- | --- | --- |
| macOS 14+, arm64 dan amd64 | Interval CPU dengan `top`, halaman RAM dengan `vm_stat`, boot dan RAM total dengan sysctl, volume startup dengan `statfs`, proses dengan `ps`, daya dengan `pmset -g batt`. | RAM bebas adalah batas bawah. Persentase proses `ps` adalah rata-rata yang meluruh. Volume APFS berbagi ruang dalam container sehingga kapasitas tidak dijumlah. Sensor suhu CPU dan perubahan profil belum tersedia melalui provider ini. |
| Windows 11 atau Windows Server 2025, amd64 dan arm64 | Win32 untuk CPU, RAM, drive tetap dengan huruf, daftar proses, waktu aktif, serta baterai dan AC. | CPU sistem pada host dengan lebih dari 64 CPU logis ditandai parsial karena kelompok prosesor. Proses terlindung dapat dilewati. RAM berasal dari tersedia fisik, dan swap Windows tidak disimpulkan dari batas commit. |
| macOS, drive fisik yang terlihat dari Disk Utility | `diskutil list -plist physical` lalu `diskutil info -plist` untuk SMART yang dilaporkan perangkat. System Information untuk dukungan TRIM NVMe/SATA yang terlihat. | Disk image dan volume logis bukan disk fisik. Alat sistem atau bridge USB dapat menyembunyikan SMART. Dukungan TRIM yang terlihat tidak memverifikasi eksekusi discard per volume. |
| Windows, disk yang terlihat dari Storage Provider | Windows PowerShell Storage menghimpun kesehatan drive dan counter reliabilitas. `fsutil behavior query DisableDeleteNotify` membaca kebijakan notifikasi NTFS/ReFS. | Kesehatan provider bukan atribut SMART mentah. Izin dapat berbeda antara health dan counters. Kebijakan notifikasi bukan bukti discard per volume. |

Metrik lokal tidak mengirim data melalui jaringan. Status alat hilang, izin, data tidak tersedia, dan galat dipertahankan. Laporan menyimpan keluarga sumber dan metrik yang diizinkan, dengan nama proses, label volume, serial, dan model drive disaring.

CI `Native providers` menjalankan tes baca-saja pada macOS 15 arm64 dan Windows Server 2025 amd64. Windows arm64 dan macOS amd64 juga dibangun lintas kompilasi. Izin administrator, laptop fisik dengan baterai, drive asli dengan SMART penuh, dan tindakan storage native belum diuji melalui runner karena perangkat yang disediakan adalah mesin virtual.
