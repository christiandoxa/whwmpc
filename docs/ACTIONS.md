# Tindakan maintenance

Jalankan aplikasi sebagai user biasa. Pemeriksaan dan preview hanya membaca keadaan host. TUI menampilkan target, kondisi awal, argv persis, izin, dampak, risiko, estimasi, expiry, dan ketersediaan pemulihan. Pilih **Lanjut ke konfirmasi**, lalu pilih **Terapkan rencana ini**. Pilihan awal di kedua langkah adalah **Batalkan**.

CLI memerlukan rencana yang ditulis eksplisit ke file baru dan ID yang disalin setelah meninjau isinya. Rencana berlaku sepuluh menit dan terikat pada host, target, kondisi awal, versi, dan operasi yang diperbolehkan. Aplikasi memverifikasi autentikasi HMAC lokal, mengunci eksekusi per state pengguna, mengklaim ID sekali, lalu menyiapkan operasi kembali dari target yang masih cocok. Rencana tidak mengizinkan argv kustom. Jika revalidasi gagal atau hasil belum diketahui, periksa keadaan dan buat preview baru sebelum mencoba lagi. Aksi dengan sudo memakai autentikasi OS dari terminal yang disuspensi. Pada non-TTY, autentikasi yang sudah tersedia melalui kebijakan sudo/polkit diperlukan.

| Tindakan | Cakupan dan pemeriksaan |
| --- | --- |
| Profil daya | API D-Bus milik power-profiles-daemon systemd dengan GUID autentikasi terpin, profil yang ditawarkan, tanpa hold dan konflik pengelola. Setelah perubahan, baca kembali ActiveProfile dan identitas daemon. Restore memakai tanda terima terverifikasi dan kondisi pembanding baru. API tidak menawarkan compare-and-set. |
| TRIM manual | Satu mountpoint Linux di jalur milik root dengan jalur discard terpetakan. BusyBox fstrim 1.35.0, 1.36.1 atau 1.37.0 membuka descriptor mount yang dipegang dan diperiksa ulang. Template argv memperlihatkan slot PID/FD numerik yang diisi executor. Jika procfs atau kebijakan privilege menolak descriptor, hasil dilaporkan dari bukti yang tersedia. Jumlah byte verbose adalah potensi discard. TRIM tidak memiliki undo. |
| Jadwal TRIM | Unit vendor `fstrim.timer` dan `fstrim.service` bawaan systemd dengan definisi yang dikenali. `enable --now` dapat memicu pekerjaan catch-up. Verifikasi unit aktif dan enabled. Restore mengembalikan konfigurasi timer tanpa membatalkan discard yang terjadi. |
| Cache APT | Ubuntu/Debian yang memakai konfigurasi standar atau cache di jalur APT tepercaya. Cakupan adalah seluruh arsip cache dan `partial`, `lists/partial`, cache biner yang dikonfigurasi dan file temporernya. APT menangani locking. Aplikasi tidak menghapus file lock atau menjalankan autoremove. |

APT memakai inventaris sendiri yang hanya membaca. `apt-get clean` memakai implementasi native dengan direktori dan RootDir terpin pada argv. Pre-setup folder cache APT dinonaktifkan, sehingga preview dan kegagalan lock tidak memerlukan perubahan mode atau ownership preemptif. Direktori yang tak terbaca dilabeli belum terukur. Verifikasi dapat menggunakan pembacaan existence-only dengan izin sudo yang sama. Byte yang diamati terhapus berasal dari inventaris yang terbaca. Perubahan ruang bebas diukur terpisah pada filesystem arsip dan dapat dipengaruhi aktivitas lain. Isi cache harus diunduh ulang bila dibutuhkan.

Ketika penghentian diminta, backend menunggu proses berhenti dalam batas waktunya dan melakukan pemeriksaan setelahnya. Output membedakan belum dimulai, terverifikasi, sebagian, gagal, dan belum diketahui. Permintaan penghentian dicatat terpisah dari hasil aktual. Tidak ada retry atau restore otomatis.

Sumber implementasi mencakup [APT 2.8 clean](https://github.com/Debian/apt/blob/2.8.0/apt-private/private-download.cc), [parser APT](https://github.com/Debian/apt/blob/2.8.0/apt-private/private-cmndline.cc), [APT file acquisition](https://github.com/Debian/apt/blob/2.8.0/apt-pkg/acquire.cc), [BusyBox 1.36.1 fstrim](https://github.com/mirror/busybox/blob/1_36_1/util-linux/fstrim.c), [fstrim util-linux 2.39.3](https://github.com/util-linux/util-linux/blob/v2.39.3/sys-utils/fstrim.c), [systemctl](https://www.freedesktop.org/software/systemd/man/latest/systemctl.html), [Power Profiles D-Bus API](https://upower.pages.freedesktop.org/power-profiles-daemon/gdbus-org.freedesktop.UPower.PowerProfiles.html), dan [Go os.Root](https://go.dev/blog/osroot).
