Audit baseline `854f277` di `christiandoxa/whwmpc`. GitHub tidak menampilkan issue atau PR terbuka saat audit. Installer memilih rilis stabil terbaru atau tag eksplisit. Upkit hanya referensi. Integrasi Upkit dibatalkan sesuai instruksi pengguna.
